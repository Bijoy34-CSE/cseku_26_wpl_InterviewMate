This folder contains the UI/UX screen designs and interface mockups for InterviewMate, an agentic AI-powered adaptive viva and interview preparation system.

The screenshots represent the main user flows and screens of the InterviewMate platform, from authentication and profile setup to interview practice, AI feedback, analytics, and readiness tracking.

🎯 Purpose

These UI designs are intended to provide a clear, modern, and user-friendly interface for:

Interview preparation

Viva and oral examination practice

AI-powered mock interviews

Adaptive question practice

AI-generated performance feedback

Performance and progress analytics

Career and academic readiness assessment

Personalized user profiles and settings
